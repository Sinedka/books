# Roadmap: Computer Systems → C → Advanced C++

Персональный маршрут изучения компьютерных систем, операционных систем, C и C++ с акцентом на внутреннее устройство языков, сложные конструкции и различия между стандартами.

**Цель:** глубоко понимать C++ — от модели памяти и правил языка до шаблонов, многопоточности и нормативного стандарта.

**Режим:** 3–4 часа в день. Срок ориентировочный: 12–18 месяцев. Поскольку основы программирования, ООП и алгоритмы уже знакомы, вводные книги исключены.

## 1. Компьютерные системы и операционные системы

### 1.1. Computer Systems: A Programmer’s Perspective (CS:APP)

**Авторы:** Randal E. Bryant, David R. O’Hallaron

Главная книга для понимания того, как программы взаимодействуют с машиной.

Изучать:
- представление целых чисел и чисел с плавающей точкой;
- машинные инструкции и ассемблер;
- компиляцию и линковку;
- устройство памяти, кэш и виртуальную память;
- процессы, сигналы и исключительные ситуации;
- основы сетевого программирования.

Ресурс: https://csapp.cs.cmu.edu/

### 1.2. Operating Systems: Three Easy Pieces (OSTEP)

**Авторы:** Remzi H. Arpaci-Dusseau, Andrea C. Arpaci-Dusseau

Изучать:
- виртуализацию CPU и памяти;
- процессы и планирование;
- потоки, блокировки и синхронизацию;
- конкурентность;
- файловые системы и хранение данных.

Полный текст доступен бесплатно: https://pages.cs.wisc.edu/~remzi/OSTEP/

### 1.3. The Linux Programming Interface

**Автор:** Michael Kerrisk

Использовать как углублённый справочник после освоения основ C и ОС.

Темы:
- системные вызовы;
- процессы и потоки;
- файловые дескрипторы;
- виртуальная память;
- сигналы и IPC;
- системные интерфейсы Linux.

## 2. Язык C

### 2.1. Effective C, 2nd Edition

**Автор:** Robert C. Seacord

Для углубления в корректность и безопасность C.

Темы:
- типы и представление объектов;
- указатели и память;
- неопределённое поведение;
- безопасная работа с ресурсами;
- ошибки, связанные с низкоуровневыми конструкциями.

Если C уже хорошо знаком, не нужно проходить книгу как вводный курс — сосредоточься на незнакомых и тонких темах.

### Что нужно уметь после этапа C

- Объяснять разницу между массивом, указателем, адресом и объектом.
- Понимать стек, динамическую память и выравнивание.
- Разбираться в компиляции и линковке многофайловых проектов.
- Читать системный код на C.
- Отличать определённое поведение от неопределённого.
- Понимать основы системных вызовов и API C.

## 3. C++: фундамент и семантика

### 3.1. The C++ Programming Language, 4th Edition

**Автор:** Bjarne Stroustrup

Фундаментальная книга для систематического понимания языка от его создателя.

Использовать для изучения:
- типов и выражений;
- объявлений и преобразований;
- классов и абстракций;
- шаблонов;
- стандартной библиотеки;
- основных принципов проектирования C++.

**Важно:** книга основана на C++11. Она не заменяет материалы по C++17, C++20, C++23 и C++26.

### 3.2. A Tour of C++, 3rd Edition

**Автор:** Bjarne Stroustrup

Краткая карта языка и его основных возможностей. Использовать для систематизации знаний и выявления пробелов, а не как единственный источник для глубокого изучения.

### 3.3. Темы для подробного изучения

- фазы трансляции, объявления и определения;
- ODR, linkage и translation units;
- типы, cv-квалификаторы и преобразования;
- lvalue, xvalue, prvalue и glvalue;
- правила инициализации и copy elision;
- overload resolution и implicit conversions;
- name lookup и argument-dependent lookup (ADL);
- время жизни объектов и временные объекты;
- неопределённое, неуточнённое и implementation-defined поведение;
- object representation, alignment и aliasing.

## 4. Современный C++ и шаблоны

### 4.1. Effective Modern C++

**Автор:** Scott Meyers

Особенно полезна для тонких практических правил C++11/14.

Темы:
- `auto` и `decltype`;
- move semantics;
- perfect forwarding;
- лямбда-функции;
- умные указатели;
- правила эффективного использования современного C++.

### 4.2. C++ Templates: The Complete Guide, 2nd Edition

**Авторы:** David Vandevoorde, Nicolai Josuttis, Douglas Gregor

Одна из главных книг для углублённого изучения шаблонов.

Темы:
- template argument deduction;
- специализация шаблонов;
- SFINAE и `enable_if`;
- variadic templates и fold expressions;
- forwarding references и `std::forward`;
- зависимые имена и двухфазный поиск;
- type traits и метапрограммирование;
- инстанцирование шаблонов.

Сайт книги: https://tmplbook.com/

### 4.3. C++20 — The Complete Guide

**Автор:** Nicolai M. Josuttis

Темы:
- concepts и constraints;
- ranges и views;
- корутины;
- modules;
- новые и изменённые возможности языка и библиотеки.

Сайт книги: https://www.cppstd20.com/

### 4.4. C++23 — The Complete Guide

**Автор:** Nicolai M. Josuttis

Продолжение для изучения возможностей C++23 и изменений стандартной библиотеки.

Сайт книги: https://www.cppstd23.com/

## 5. Многопоточность

### C++ Concurrency in Action, 2nd Edition

**Автор:** Anthony Williams

Темы:
- модель памяти C++;
- `std::thread` и `std::jthread`;
- mutex и condition variables;
- атомарные операции;
- `memory_order`;
- happens-before и гонки данных;
- проектирование потокобезопасных компонентов.

Эту книгу лучше читать после понимания времени жизни объектов, RAII и базовой семантики C++.

## 6. Стандарт и различия версий

Изучай изменения между редакциями не только как список новых ключевых слов. Для каждой версии выясняй:
1. Что добавлено в Core Language.
2. Что добавлено в стандартную библиотеку.
3. Какие существовавшие правила изменились.
4. Какие defect reports исправили ранее опубликованные стандарты.
5. Какие возможности поддерживаются компиляторами.
6. Какие предложения ещё не стали частью принятого стандарта.

### Основные версии

| Версия | Основные темы |
|---|---|
| C++98/03 | Базовая модель языка, классы, шаблоны, исключения, RTTI |
| C++11 | Move semantics, rvalue references, lambdas, `auto`, `decltype`, `constexpr`, variadic templates, модель памяти |
| C++14 | Generic lambdas, relaxed `constexpr`, вывод возвращаемого типа, variable templates |
| C++17 | Structured bindings, `if constexpr`, fold expressions, CTAD, inline variables, гарантированная copy elision |
| C++20 | Concepts, ranges, coroutines, modules, `consteval`, `constinit`, трёхстороннее сравнение |
| C++23 | Deducing `this`, `if consteval`, `std::expected`, `std::print`, улучшения ranges и `constexpr` |
| C++26 | Проверять принятую редакцию, статус предложений и поддержку компилятора по актуальным источникам |

**Не путай** возможности Core Language, возможности стандартной библиотеки, defect reports и расширения конкретного компилятора.

## 7. Рекомендуемый порядок

| Этап | Материалы | Основная цель |
|---|---|---|
| 1 | CS:APP + выбранные главы OSTEP | Машинный код, память, процессы и ОС |
